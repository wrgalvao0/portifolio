Hospedagem+

Este projeto consiste em uma plataforma online altamente intuitiva e responsiva, projetada para oferecer uma experiência de usuário simplificada e eficiente. A plataforma permite que os usuários façam login de maneira segura e fácil, oferecendo acesso a uma vasta seleção de hotéis cuidadosamente cadastrados. Os usuários podem, então, explorar as opções disponíveis para verificar a disponibilidade de reservas em tempo real. A interface da plataforma foi desenvolvida com um design moderno e elegante, garantindo que todos os elementos sejam visualmente agradáveis e funcionais. Além disso, a plataforma é completamente responsiva, ou seja, ela se adapta perfeitamente a diferentes dispositivos, como desktops, tablets e smartphones, proporcionando uma experiência fluida e sem interrupções. Toda a navegação e interações dentro da plataforma foram otimizadas para garantir uma performance rápida e sem falhas, tornando o processo de busca e reserva de hotéis uma tarefa rápida, fácil e prazerosa.

Hora certa

Este projeto é uma plataforma de e-commerce especializada na venda de relógios, com uma interface moderna, responsiva e intuitiva, projetada para oferecer uma experiência de compra agradável e eficiente. A plataforma conta com um menu de navegação fácil de usar, permitindo que os usuários encontrem rapidamente o que procuram. Além disso, inclui banners promocionais para destacar ofertas especiais, produtos em destaque que chamam a atenção para as melhores opções, e uma galeria de clientes com depoimentos que ajudam a criar confiança. O rodapé da plataforma é interativo, oferecendo informações de contato e facilitando o acesso a políticas da empresa, como formas de pagamento e devolução. Tudo foi projetado para proporcionar uma experiência de compra fluida, prática e envolvente, tornando o processo de escolha e compra de relógios mais simples e agradável.Além disso, a plataforma foi otimizada para garantir um carregamento rápido e uma navegação sem interrupções, proporcionando uma experiência fluida e sem frustrações. A segurança também é uma prioridade, com recursos de proteção de dados e transações, garantindo que os usuários se sintam seguros durante todo o processo de compra. Com um design atraente e uma navegação simples, o e-commerce oferece uma experiência completa, desde a escolha do produto até a finalização da compra.

Avalia RU Unifesspa

Este projeto envolve o desenvolvimento de um sistema web que permite à comunidade acadêmica avaliar as refeições oferecidas no restaurante universitário. A plataforma conta com uma página de login para acesso seguro, uma página de cadastro para novos usuários e uma página de avaliação onde os usuários podem classificar as refeições e deixar comentários sobre a qualidade dos pratos. Além disso, o sistema possui uma área administrativa exclusiva para que o administrador consulte dados estatísticos sobre as avaliações realizadas, como médias de notas e feedbacks por dia. Esse recurso visa ajudar na melhoria contínua do serviço oferecido. Este projeto é parte do meu trabalho de conclusão de curso de graduação em Engenharia da Computação, e tem como objetivo otimizar a gestão das refeições no restaurante universitário e promover a participação ativa da comunidade acadêmica na avaliação dos serviços prestados.O sistema foi desenvolvido com foco na simplicidade e usabilidade, garantindo que todos os usuários, independentemente de sua familiaridade com tecnologia, possam utilizar a plataforma de maneira eficiente. A interface foi projetada para ser intuitiva, proporcionando uma navegação fácil e rápida entre as diferentes páginas. Além disso, a segurança foi uma prioridade no desenvolvimento, com medidas para proteger os dados pessoais dos usuários e garantir a integridade das informações registradas nas avaliações
